# Настройки → создание окружения → запуск

Дата: 2026-10-28. Проверен основной сценарий, уточнённый пользователем в чате.

В настройках работают добавление инфраструктуры из образа и целевых сервисов
из образа либо папки с Dockerfile, редактирование env/ports/storage defaults,
сохранение и включение/скрытие сервисов в каталоге создания. Данные сохраняются
в SQLite; миграция 003 добавляет выбор версии и доступность компонента.

При создании используются сохранённые настройки. Галочки управляют составом,
команда «Ещё один» добавляет отдельный экземпляр. Каждый экземпляр имеет свои
env-переменные, порты и хранилища. «Сохранить и запустить» сначала сохраняет
конфигурацию, затем открывает Inspect и вызывает обычный Start.
Пустой список окружений показывает переход к настройкам и созданию.
Каталоги располагаются друг под другом в узкой рабочей области.

Изменение defaults не меняет сохранённые окружения. Изменение папки создаёт
новую локальную ссылку; прежние snapshots продолжают указывать на прежнюю папку.
Исторические версии доступны для разрешения зависимостей, а в каталоге создания
показаны выбранные и включённые версии.
