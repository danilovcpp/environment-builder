# Библиотека компонентов и настройки среды

Дата: 2026-10-28. Уточнения из текущего запроса пользователя.

В библиотеке редактируются имя, источник (образ или папка), иконка и цвет.
Целевые сервисы также выбирают зависимости из уже добавленных компонентов
библиотеки; инфраструктурные компоненты не показывают этот редактор.
Зависимость может быть обязательной или необязательной. Обязательные компоненты
добавляются в среду автоматически. Необязательные включаются отдельно и после
включения участвуют в порядке запуска. Циклы и дубли запрещены.

Env, порты, хранилища, параметры, Dockerfile, контекст, аргументы и секреты сборки
редактируются у экземпляров при создании/изменении среды. Новая форма библиотеки
не содержит редактора этих значений. Существующие snapshots и импорт прежних
описаний сохраняют совместимость. Изменение библиотеки создаёт новые версии
описаний и согласованные ссылки зависимостей для будущих сред.

Для инфраструктуры ввод имени образа запускает поиск Docker Hub с задержкой
350 мс и отменой устаревших запросов. Выбор загружает теги страницами по 100
и логотип из метаданных/описания при наличии поддерживаемого изображения.
Ручной образ и тег остаются доступны при ошибках сети. Отсутствующий логотип
заменяется выбранной иконкой. Логотип, иконка и цвет сохраняются в описании
и используются в библиотеке и каталоге создания среды.

Публичные endpoints поиска, тегов и метаданных проверены на Docker Hub Redis.
Автоматические тесты API используют подготовленные HTTP-ответы; живой Docker
для этой доработки не запускался.
