# UX-аудит и изменения интерфейса · 28 октября 2026

## Метод

Экспертный аудит двух предоставленных скриншотов, навигации, общих WPF-компонентов и основных экранов приложения. Проверка сценариев создания, редактирования, просмотра окружения, работы с библиотекой сервисов и тестовыми данными. Это эвристический аудит; исследование с участием пользователей не проводилось.

Основание для решений: [команды и их приоритет в Windows](https://learn.microsoft.com/en-us/windows/apps/design/controls/command-bar), [настройки приложения](https://learn.microsoft.com/en-us/windows/apps/design/app-settings/guidelines-for-app-settings), [навигация](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics). Рекомендации применены к существующему WPF-интерфейсу без смены технологии или палитры.

## Найденные проблемы и решения

| Проблема | Почему мешает | Изменение |
|---|---|---|
| Команды страницы в дальнем правом углу, рядом с системным закрытием | Большое перемещение указателя от списка; команды оторваны от рабочего контекста | Панель команд под названием страницы, слева; перенос по доступной ширине |
| Первичное действие после вторичных | Слабая иерархия | «Создать окружение» первым; импорт и экспорт после него |
| «Настройки» фактически содержат сервисы | Название не соответствует содержимому | Раздел «Сервисы» в основном меню; отдельный маршрут `services` |
| Тема переключается нажатием «Локальный режим» | Управление невозможно предсказать по подписи | Явный выбор темы в настоящих настройках; локальный режим — информационная подпись |
| Нет страницы параметров приложения | Негде найти персональные предпочтения | «Настройки» закреплены внизу меню; группы «Внешний вид», «Запуск», «О приложении и хранилище» |
| Тема не сохраняется | Каждый запуск требует повторной настройки | Автосохранение темы, начального раздела и видимости описаний в `preferences.json` внутри локального хранилища |
| Нет следования теме Windows | Приложение не учитывает системное предпочтение | «Как в Windows», светлая и тёмная темы; подписка на изменение системной темы |
| Кнопки для выбранного окружения внизу большого окна | Объект и действия далеко друг от друга; контекст неясен | Блок над списком с именем выбранного окружения; показывается при выборе |
| Непонятная длинная подпись восстановления | Техническая терминология перегружает панель | «Восстановить данные»; точные последствия остаются в подсказке и существующем подтверждении |
| Имя без описания визуально смещено вверх | Пустой TextBlock и его отступ резервируют вторую строку | Пустое описание сворачивается; одиночное имя центрируется |
| Иконки внутри плиток смещены | Задано только вертикальное выравнивание | Общее центрирование иконок по обеим осям; единые размеры |
| Текст рядом с иконками выше визуального центра | Текст и пиктограмма имеют разную высоту | Общий стиль подписи кнопок с вертикальным центрированием |
| Статусы окружений отмечены одинаковой серой точкой | Ошибки и требующая сверки операция плохо различимы | Семантические цвета и текст статуса; информация не зависит только от цвета |
| Фильтры и длинные команды съедают высоту маленького окна | Для строк остаётся слишком мало места | В компактном режиме состояния выбираются в выпадающем списке; команды переносятся с сохранением интервалов |
| Показатели ресурсов ещё не подключены | Пустые полосы похожи на измерение | Блок ресурсов сохранён, явно показывает «Нет данных»; в узком окне подробности доступны в раскрытом составе |
| Запланированные функции выглядят доступными | Нажатие не даёт ожидаемого результата | Импорт, экспорт и создание пакета сохранены; временно отключены с подсказкой «В разработке» |
| Добавление сервиса дублируется в двух местах | Два одинаковых входа без разницы в поведении | Добавление остаётся у библиотеки; сохранение и отмена изменений находятся в общей панели страницы |
| Старые подсказки ведут в «Настройки» за сервисами | После переименования пользователь ищет не тот раздел | Пустой список и редактор направляют в «Сервисы» |
| Системная иконка исполняемого файла | Приложение трудно узнать в панели задач и переключателе окон | Общая векторная иконка куба для приложения; ICO с 9 размерами от 16 до 256 px для EXE и заголовка |

Запланированные функции и незаполненные блоки сохранены по уточнению пользователя. Новый UX не имитирует их готовность. Подтверждения удаления, очистки и восстановления данных продолжают использовать существующие планы операций.

## Проверка

- Сборка Release с анализаторами и предупреждениями как ошибками.
- Модульные тесты, включая запись, повторное чтение и валидацию персональных настроек.
- Интеграционные тесты с изолированными хранилищами.
- WPF-проверки обеих тем при 960×600, 1280×720 и 1672×941 DIP; снимки экранов, состояния контролов и ошибки привязок.
- Отдельные проверки сохранения настроек между экземплярами модели, переключения темы, разделения маршрутов и центрирования имени без описания.
- Настоящие клавиатурные сценарии через страницу настроек, создание окружения и просмотр Compose.

PNG и TRX текущего прогона: `.artifacts/ui-ux/` и `.artifacts/ux-tests/`. Масштаб снимков соответствует текущему DPI рабочего стола; другие системные масштабы требуют отдельного прогона.

Результат: Release собирается без предупреждений и ошибок; 110 модульных, 274 интеграционных и 3 UI-теста прошли. Один opt-in тест настоящего Docker пропущен по штатному условию. Проверки Windows ACL и настоящего ввода выполнены за пределами ограничений песочницы. Фактический масштаб снимков — 144 DPI (150%). Отдельно проверены видимость всех четырёх действий строки при 960 DIP, применение настройки описаний и восстановление начальной страницы после перезапуска процесса. Из EXE извлечена новая иконка; ICO содержит 9 размеров.
